Rate Calculator

A small project to investigate python and agentic programming. I wanted to be able to compare rates across different roles and truly understand the take home pay including factors like pension contributions which other online calculators didn't provide. While I know some python and HTML this was an exercise in using both Anthropic and OpenAI agents to create the code based on my instructions about calculation and design.
